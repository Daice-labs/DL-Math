# DL-Math
Mathematical articles and proofs from Dandela at Daice Labs.

| Result | Theorem and scope | Read the proof |
| --- | --- | --- |
| Haralambis’s three-distance conjecture | For every three-element set of positive integer distances, $D=\{a,b,c\}$, the maximum avoiding density $\mu(D)$ equals the circular-distance bound $\kappa(D)$. A periodic set attains the value. The proof also bounds the number of occupied sites on every finite interval. | [Paper proof](haralambis/proof.md) · [Proof clarifications](haralambis/proof-clarifications.md) · [Lean sources](haralambis/lean-sources.zip) |
| Erdős–Sós problem 865, pairwise sums | For each fixed $k\ge2$, the cardinality threshold for forcing $k$ distinct elements and all their off-diagonal pair sums in a subset of $[N]$ is asymptotic to $\frac23(1-4^{1-k})N$. | [Article (PDF)](erdos-sos-865/article.pdf) · [Induction proof](erdos-sos-865/proof.md) · [Supplement](erdos-sos-865/supplement.md) · [Lean sources](erdos-sos-865/lean-sources.zip) |
| Tuza’s triangle packing and covering conjecture | The residual-component cover theorem and the exclusion of diamond and four-cycle common neighborhoods in a minimal counterexample with maximum degree 11 and edge codegree at most four. The full degree-eleven case remains open in this work. | [Residual-component theorem](tuza/residual-theta-theorem.md) · [Common-neighborhood proofs](tuza/common-neighborhoods/proof.md) |
| Extended Frege, extended resolution and complete B7 | Polynomial-time translations of supplied refutations preserve the original CNF for the complete B7 system, signed ER and fixed finite-basis EF specified in the paper. The bounds count bit operations and include the supplied witnesses and local certificates. | [Definitions, translations and size bounds](ef-er-b7/equivalence-proof.md) |
| Paired guards in cubic parity formulas | For the specified shuffled 3-CNF encoding on connected simple cubic graphs, odd charge has an Extended Frege refutation with $O(n\log(n+2))$ lines. At even charge, every guard assignment extends to a satisfying assignment. | [Construction and proof](guarded-cubic-parity/proof.md) |
| Binary-linear couplings over the field of eight elements | All 512 couplings fall into three classes. Their trace distributions give exact counts of compatible factorizations of each nonzero field element. | [Classification and counting formulas](f8-linear-couplings/proof.md) |
| Nullstellensatz degree and an odd-prime family | The specified 25-variable source has exact static degree four. A family proof establishes inconsistency under cyclotomic irreducibility. | [Proof and explicit certificates](nonlinear-degree-boundary/proof.md) |
| Uniform binary affine refutations | An inconsistent $m$-row, $n$-column binary affine system has a checked PB+RED construction with at most $23mn+3$ derived constraints. | [Proof and Lean sources](affine-refutations/proof.md) |
| Taylor cancellation and signed Hermite recovery | Inactive variables cancel in correction blocks. Exact endpoint recovery from positive nodes requires a negative weight. | [Counting and sign proofs](sparse-taylor-counting/proof.md) |
| Schnorr’s parity lower bound | A uniform formal construction realizes the classical $3(n-1)$ gate lower bound in the specified two-input basis. | [Circuit argument and Lean project](schnorr-parity/proof.md) |
| Counting on odd-prime sources | A component decomposition counts compatible pairs. Reciprocal symmetry transports labeled ranks and gives 3,065 orbits for the 6,050 nonempty obligations at $p=73$. | [Counting and rank proofs](odd-prime-counting/proof.md) |
| Conditional subexponential Extended Frege construction | For every fixed clause width, the paper derives a subexponential dependence on the original variable count for EF size and construction time, conditional on the four stated external premises. | [Premises, proof and costs](conditional-ef/proof.md) |
| Supplied graded counting traces | Abstract capacity descent and a polynomial bound on proof length and construction time for the supported schedule, measured in the complete supplied input length. | [Descent and cost proof](supplied-graded-traces/proof.md) |
| Spoke-status constraints in cubic mod-3 flow formulas | Arbitrary signed two-literal spoke-status constraints on the specified family admit polynomial-time decision, model lifting and clausal refutation. The three-literal extension encodes 3-SAT. | [Paper theorem and Lean core](spoke-status/proof.md) |
