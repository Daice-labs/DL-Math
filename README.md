# DL-Math
Mathematical articles and proofs from Dandela at Daice Labs.

| Result | Theorem and scope | Read the proof |
| --- | --- | --- |
| Haralambis’s three-distance conjecture | For every three-element set of positive integer distances, $D=\{a,b,c\}$, the maximum avoiding density $\mu(D)$ equals the circular-distance bound $\kappa(D)$. A periodic set attains the value. The proof also bounds the number of occupied sites on every finite interval. | [Paper proof](haralambis/proof.md) · [Proof clarifications](haralambis/proof-clarifications.md) · [Lean sources](haralambis/lean-sources.zip) |
| Erdős–Sós problem 865, pairwise sums | For each fixed $k\ge2$, the cardinality threshold for forcing $k$ distinct elements and all their off-diagonal pair sums in a subset of $[N]$ is asymptotic to $\frac23(1-4^{1-k})N$. | [Article (PDF)](erdos-sos-865/article.pdf) · [Induction proof](erdos-sos-865/proof.md) · [Supplement](erdos-sos-865/supplement.md) · [Lean sources](erdos-sos-865/lean-sources.zip) |
| Tuza’s triangle packing and covering conjecture | A maximum packing gives $\tau(G)\le 2\nu(G)$ under the empty-private-family and minimum packing-load hypotheses when each residual component is a tree, a cycle or a theta graph. The path lengths in a theta component may be arbitrarily large. The degree-eleven case remains open in this work. | [Theorem, hypotheses and proof](tuza/residual-theta-theorem.md) |
| Extended Frege, extended resolution and complete B7 | Polynomial-time translations of supplied refutations preserve the original CNF for the complete B7 system, signed ER and fixed finite-basis EF specified in the paper. The bounds count bit operations and include the supplied witnesses and local certificates. | [Definitions, translations and size bounds](ef-er-b7/equivalence-proof.md) |
